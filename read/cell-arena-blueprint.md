## 0. 고정된 큰 축 (건드리지 않은 것)

| 축 | 내용 |

| POMDP | 세포 중심 에고센트릭 시야. 크기가 클수록 넓게, 대신 거칠게 봄 |
| 커리큘럼 | 이산·정지환경 → 연속·정지환경 → 연속·적대환경 (복잡도 3단 상승) |

| 속도 | JAX 병렬 롤아웃, 실습당 1시간 학습 |

### V러닝은 어디로 갔나

관측이 연속·부분관측이라 상태 열거가 원천 불가 → 테이블 기반 V/Q는 폐기.
**대신 V는 Lab 2에서 PPO의 critic(baseline)으로 부활한다.** 원래 의도했던
`V → Q → π` 개념 사슬은 `Q(Lab1) → π + V(Lab2)`로 재배치되어 그대로 살아 있음.

## 1. 세계

### 1.1 좌표계와 스케일

- 맵: `L = 100` (변수), **토러스** — 경계 없음, 상하좌우 wrap
- 거리 계산은 항상 최소상(minimal image) 규약:
  `dx = ((x1 - x2 + L/2) mod L) - L/2`
- **크기 `s`** = 스칼라 자원 (질량). 기본 세포 `s = 100`, 승리 `s = 1000`
- **직경 `d(s) = √(s / 100)`** — 면적이 크기에 비례(먹으면 질량 보존)
  - `s=100 → d=1.00` / `s=500 → d=2.24` / `s=1000 → d=3.16`
  - 밥 `s=8 → d=0.28`

> 맵 폭 100은 기본 세포 직경의 100배, 최대 세포 직경의 32배. 추격에 충분한 공간.

### 1.2 객체 5종

| 객체 | 크기 | 개수(기본) | 상호작용 |
|---|---|---|---|
| **세포** | 100 ~ 1000 | N (에이전트+봇) | 큰 쪽이 작은 쪽 흡수 (아래 조건) |
| **밥** | Exp(평균 8), 상한 40 | 300 | 세포가 무조건 흡수, `+0.5 × 밥크기` |
| **블랙홀** | 500 고정 | 15 | `s < 500`: 무해 / `s > 500`: 소멸시키고 **−250** |
| **화이트홀** | 500 고정 | 15 | `s < 500`: 소멸시키고 **+100** / `s > 500`: 무해 |
| **세포밥** | 방출 세포 크기의 0.5% | 동적 | 밥과 동일 규칙, 색은 방출 세포 색 |

### 1.3 포식 판정

```
포식 성립 ⟺  dist(A, B) < r_A  AND  s_A > 1.1 × s_B
```

- `r_A = d(s_A)/2` — 작은 쪽 중심이 큰 쪽 원 안에 들어와야 함
- **1.1배 임계**는 원 명세에 없던 추가. 비슷한 크기끼리 스치듯 잡아먹는 knife-edge를
  없애고 **교착 구간(standoff band)** 을 만든다. 대전이 훨씬 읽기 좋아지고 학습 노이즈도 감소.

### 1.4 스폰 규칙

밥·블랙홀·화이트홀 모두 **모든 세포 시야의 합집합 바깥**에서만 스폰.
시야 안에 객체가 순간이동하듯 나타나는 상황을 막기 위함.

**폴백 필수**: 세포가 많거나 커지면 시야 합집합이 맵을 거의 덮어 스폰 불가에 빠진다.

```
후보 K=32개 균등 샘플 → 모든 시야 밖인 것만 남김
  ├─ 남은 게 있으면: 그중 랜덤
  └─ 하나도 없으면: 후보 중 "가장 가까운 세포까지 거리"가 최대인 점
```

폴백이 발동해도 최대한 먼 곳에서 생기므로 순간출현 문제는 실질적으로 억제됨.

## 2. 운동 모델 (관성 있음)

### 2.1 속도

```
v_base(s) = (s / 100) ^ (−0.19)
D(s)      = 1 + s / 1000          ← 돌진 배율 (크기 비례)
v_dash(s) = v_base(s) × D(s)
```

| 크기 | 평상 속도 | 돌진 속도 |
|---|---|---|
| 100 | 1.00 | 1.10 |
| 300 | 0.82 | 1.06 |
| 500 | 0.74 | 1.11 |
| 1000 | 0.65 | **1.30** |

> **⚠ 원 명세에서 바꾼 핵심.** 원안(최대 0.7 + 돌진 1.5× 고정)이면 큰 세포 돌진이 1.05로
> 작은 세포 1.00을 겨우 5% 앞서 사실상 못 잡는다. **돌진 배율을 크기 비례로** 만들면
> 의도가 정확히 성립한다:
> - 큰 세포는 평상시 0.65라 **아무도 못 잡음** (작은 세포 1.00에게 농락당함)
> - 돌진하면 1.30으로 **누구든 따라잡음** — 단, 크기를 태워가며
> - 작은 세포는 돌진해도 1.10이라 **도망으로는 못 살아남음** → 각도로 피해야 함

### 2.2 조향 (관성)

```
v_target = 방향단위벡터 × 속도(위 표)
v       ← v + (v_target − v) × κ_eff

κ(s)    = 0.35 × (s / 100) ^ (−0.25)
κ_eff   = κ(s) × 0.5   (돌진 중)
         = κ(s)        (평상시)
```

| 크기 | κ (평상) | κ (돌진) |
|---|---|---|
| 100 | 0.350 | 0.175 |
| 500 | 0.234 | 0.117 |
| 1000 | 0.197 | **0.099** |

**이게 게임의 스킬 축이다.** 큰 세포는 돌진으로 빠르지만 선회가 3.5배 둔해 오버슈트한다.
작은 세포는 느려도 급회전으로 각을 끊어 산다. "돌진 = 커밋" 이라는 긴장이 생김.

### 2.3 돌진 비용

- **최소 크기 100**: `s ≤ 100`이면 돌진 불가. 기본 세포는 돌진을 쓸 수 없다 → **돌진은 성장의 특권**
- 돌진 중 **4스텝마다** 현재 크기의 **0.5%** 를 세포밥으로 방출 (그만큼 감소)
- 방출로 `s`가 100 아래로 갈 상황이면 돌진 자동 해제
- 움직이지 않으면 돌진 무시 (제자리 돌진 없음)

**추격 경제성 검산**: `s=1000` 세포가 40스텝 추격 → 10회 방출 × 5 = **−50**.
`s=300` 세포를 잡으면 **+300**. 순이익 +250. 사냥은 남는 장사지만 공짜가 아니다.

## 3. 관측 (POMDP)

### 3.1 시야

```
시야 반경  h(s) = 8 × d(s),  상한 25
```

| 크기 | 시야 반경 | 시야 한 변 | 맵 대비 면적 |
|---|---|---|---|
| 100 | 8.0 | 16 | 2.6% |
| 500 | 17.9 | 35.8 | 12.8% |
| 1000 | 25.0 (캡) | 50 | 25% |

> **⚠ 원 명세에서 바꾼 것.** 원안 `시야 = 크기×10`이면 기본 세포 시야가 1000×1000으로
> **맵(100×100)의 100배**가 되어 붕괴한다. 직경 기준 + √크기 스케일로 재정의.
> 상한 25는 "아무리 커도 맵 전체는 못 본다"를 보장해 스폰 규칙과 POMDP를 지킨다.

### 3.2 공통 자기 상태 (두 모드 모두 제공)

```
[ s/1000,  d(s),  v_x,  v_y,  h(s)/25,  dash_available ]
```

자기 크기 제공은 필수 — 이미지에서 "저 원이 나보다 큰가"를 판단할 스케일 기준이 된다.

### 3.3 모드 A — 상태벡터 (주 학습 경로 ★)

- 시야 안 객체를 거리순으로 최대 `M`개 (기본 32)
- 객체당 4~7 스칼라:
  - 좌표 2개: **직교 상대좌표** `(dx, dy)` 또는 **극좌표** `(r, θ)` 선택
  - 직경 1개
  - 타입 원핫 4개 (밥 / 블랙홀 / 화이트홀 / 다른세포)
    - *세포밥은 밥과 규칙이 같으므로 밥 타입으로 통합 (원하면 5번째 채널로 분리)*
- 부족분은 0 패딩 + 마스크

**순열 문제(설계된 함정)**: 이 리스트는 순서가 바뀌면 신경망 입력이 완전히 달라진다.
사용자가 직접 해결해야 함:

| 방법 | 난이도 | 특징 |
|---|---|---|
| 거리순 정렬 + MLP | 쉬움 | **Lab 1 권장.** 잘 되지만 객체 순위가 뒤바뀌는 순간 입력이 점프(불연속) |
| DeepSets (합/최대 풀링) | 중간 | permutation-invariant 보장, 구현 간단 |
| 위치임베딩 없는 셀프어텐션 | 어려움 | 표현력 최고, Lab 3 고급 트랙 |

> 거리정렬이 "싼 우회로인데 은근히 통하다가 특정 상황에서 깨지는" 것 자체가 좋은 교보재.
> Lab 1에서 정렬로 시작 → 깨지는 지점 체감 → Lab 3에서 어텐션 도입, 이 흐름을 권장.

### 3.4 모드 B — 이미지 (관전 + 고급 트랙)

- 시야를 고정 해상도 `R×R` 텐서로 렌더 (기본 64×64, 조절 가능)
- **시야 물리 크기는 커지는데 텐서는 고정** → 큰 세포일수록 넓지만 저해상도 (의도된 트레이드오프)
- 3채널 RGB(사람이 보는 그대로) 또는 5채널 시맨틱(타입별 분리, 학습 훨씬 빠름)
- 도트 그래픽: 1 게임유닛 = 8×8 도트 기준으로 렌더

**이미지 모드의 주 용도는 학습이 아니라 관전·디버깅.**
1시간 학습 예산에 CNN은 부담이 크다. "에이전트가 지금 뭘 보고 있는지"를 사람이 보는
창으로 쓰고, 학습은 상태벡터로 하는 걸 기본으로 권장.

## 4. 액션

### 4.1 모드 A — 직교 이산 (Lab 1, DQN)

```
MultiBinary(5) = [상, 하, 좌, 우, 돌진]
```

- 대각선 동시 입력 → `1/√2` 배로 정규화
- 대치 방향 동시 입력 → 상쇄(무시)
- 결과적으로 실효 이동은 **9가지**(8방향 + 정지) × 돌진 2 = **18가지**

> DQN 구현 편의를 위해 `Discrete(18)` 정규화 인터페이스를 함께 제공.
> `MultiBinary(5)`(=32조합, 중복 포함)가 "진짜" 인터페이스이고 18은 그 canonical 축약.

### 4.2 모드 B — 극좌표 연속 (Lab 2+, PPO)

```
[ θ ∈ [−π, π] 연속,  move ∈ {0,1},  dash ∈ {0,1} ]
```

- **혼합 액션 공간**: 정책 네트워크가 머리 3개
  - θ: tanh 스쿼시 가우시안 (또는 **von Mises** — 각도의 wrap-around를 제대로 다루는 정론)
  - move, dash: 베르누이 각 1개
  - 로그확률은 셋을 더함
- 부담되면 **단계 도입**: Lab 2 초반엔 `move=1` 고정하고 θ만 학습 → 되면 move/dash 헤드 추가

### 4.3 이게 곧 커리큘럼의 벽

| | Lab 1 | Lab 2 |
|---|---|---|
| 관측 | **동일** | **동일** |
| 물리 | **동일** | **동일** |
| 액션 | 방향을 18개 중 선택 | 방향을 연속 각도로 지정 |
| 알고리즘 | DQN (argmax 가능) | PPO (argmax **불가능**) |

바뀌는 변수가 **액션 표현 딱 하나**. 깨끗한 대조 실험이 되도록 관측을 통일한 것이 핵심.

## 5. 보상

```
r_t = Δs_t / 100
    + (죽었으면 −1.0)
    + (s ≥ 1000 도달 시 +5.0)
```

`Δs` 하나로 모든 사건이 자연스럽게 조밀한 보상이 된다:

| 사건 | 보상 |
|---|---|
| 밥 (평균 8) | +0.04 |
| 화이트홀 | +1.00 |
| 블랙홀 | **−2.50** |
| 돌진 방출 1회 (s=1000) | −0.05 |
| 킬 (s=300 흡수) | +3.00 |
| 사망 | −1.00 |
| 승리 | +5.00 |

- 스텝 페널티 불필요 (돌진 비용과 시간압이 이미 존재)
- **고급 옵션**: `r = Δlog(s)` 로 두면 스케일 불변이 된다 — 크기 100에서 +100과
  크기 1000에서 +100의 가치 차이가 자동 반영. 분산도 줄어듦. Lab 3에서 권장.

**의도된 크레딧 할당 난이도**: 돌진은 즉시 음수 보상이고 킬은 수십 스텝 뒤에 온다.
이걸 학습하는 게 Lab 2/3의 핵심 과제.

## 6. 커리큘럼 (3 랩 + 데모)

### Lab 0 — 데모 (30분, 학습 없음)

- 스크립트 봇들이 노는 걸 관전. 이미지 모드로 "에이전트 시야" 창 띄우기
- 설명: *"관측이 연속이고 부분적이라 상태를 셀 수 없다. 그래서 처음부터 함수근사로 간다"*
  → V/Q 테이블을 건너뛰는 정당화

### Lab 1 — DQN (값기반 기준선)

| 항목 | 설정 |
|---|---|
| 액션 | 직교 이산 `Discrete(18)` |
| 관측 | 상태벡터, 거리정렬, M=32, MLP |
| 상대 | 스크립트 봇 (정지 → 랜덤워크 → 탐욕 추격) 3단계 |
| 과제 | 밥 채집, 블랙홀 회피, 큰 세포 회피, 화이트홀 우선순위 |
| 옵션 토글 | replay buffer, target network, Double DQN |

**여기선 DQN이 잘 된다.** 이게 포인트 — 정지된 환경 + 이산 액션에서 값기반은 충분하다는
기준선을 세워야 Lab 2의 대비가 산다.

*성공 기준 예: 랜덤 정책 대비 평균 최종 크기 3배 이상, 블랙홀 충돌률 <5%*

### Lab 2 — PPO (정책기반, 연속 액션)

| 항목 | 설정 |
|---|---|
| 액션 | **극좌표 연속** `[θ, move, dash]` |
| 관측 | Lab 1과 완전 동일 |
| 상대 | Lab 1과 동일 (변수 통제) |

**벽**: 연속 각도 → `max_a Q(s,a)` 물리적으로 불가능 → 정책을 직접 파라미터화해야 함

**여기서 V가 critic으로 부활한다.** advantage = 실제 리턴 − V(s).
원래 커리큘럼의 V러닝이 "정책 개선의 baseline"이라는 제 위치를 찾아 돌아오는 지점.

**PG의 고통 압축 아크 (앞 30분)**:
1. REINFORCE 순수 버전 → 시드별 학습곡선이 미쳐 날뛰는 걸 목격 (분산)
2. baseline(critic) 추가 → 안정화 확인
3. "모은 데이터를 여러 epoch 재사용하면 효율 오르지 않나?" → IS 비율 폭발 → 학습 붕괴
4. **비율을 clip하니 산다** → PPO

> 정책기반의 당위는 여기서 완성된다. clip이 무슨 문제를 푸는지는 **직접 터뜨려봐야** 납득된다.

## 7. 밸런스 근거

### 7.1 성장 경로 (100 → 1000)

| 구간 | 주 수단 | 근거 |
|---|---|---|
| 100 → 500 | **화이트홀 4개 + 밥** | 화이트홀은 `s<500`에서만 발동 → 중반까지 고속 성장 |
| 500 → 1000 | **킬 + 밥** | 화이트홀 무효화 → 사냥 강제. 블랙홀(−250)이 상시 위협 |

**자기 균형 루프**: `s>500` 세포가 블랙홀을 밟으면 −250 → 다시 500 아래로 → 화이트홀 재발동.
큰 세포가 무한 성장하지 않고 중간 대역으로 되돌려지는 구조. (사용자 의도 그대로)

### 7.2 크기별 처지

| 크기 | 속도 | 돌진 | 시야 | 처지 |
|---|---|---|---|---|
| 100 | 1.00 (최속) | **불가** | 좁음 | 기민하지만 무기 없음. 도망만 |
| 300 | 0.82 | 1.06 | 중간 | 가장 균형. 밥·화이트홀 사냥 |
| 500+ | 0.74 | 1.11 | 넓음 | 화이트홀 끊김, 블랙홀 위험 시작 |
| 1000 | 0.65 (최저) | **1.30 (최속)** | 최대(캡) | 돌진 없인 무력, 돌진하면 최강. 대신 출혈+블랙홀 |

### 7.3 블랙홀 = 작은 세포의 유일한 견제 수단

큰 세포는 평상시 0.65로 느리고 선회 κ=0.197로 둔해 **블랙홀 회피가 어렵다**.
작은 세포가 큰 세포를 블랙홀 쪽으로 유인하는 플레이가 창발할 여지가 있음. (의도된 시너지)

### 7.4 에피소드 길이 추정

- 밥 300개, 시야 16×16에 평균 ~5개 보임
- 밥 하나당 +4, 화이트홀 +100
- 유능한 에이전트 기준 1000 도달까지 **약 1500~2500 스텝**
- 에피소드 상한 **3000 스텝** 권장

## 8. JAX 구현 노트

```python
# 상태는 전부 고정 크기 배열 + active 마스크 (동적 할당 금지)
cells      = {pos: (N,2), vel: (N,2), size: (N,), alive: (N,), color: (N,)}
objects    = {pos: (M,2), size: (M,), type: (M,), alive: (M,)}   # M=400 정도 여유
```

| 항목 | 방법 |
|---|---|
| 토러스 거리 | `dx = jnp.mod(x1 - x2 + L/2, L) - L/2` |
| 충돌 판정 | 세포×세포 O(N²) (N≤16, 무시), 세포×객체 O(N·M) ≈ 6400 — vmap으로 즉시 |
| 관측 top-M | `jax.lax.top_k(-distance, M)` |
| 스폰 | 후보 K=32 균등샘플 → 시야 마스크 → 없으면 `argmax(min_dist)` |
| 롤아웃 | `jax.lax.scan` over steps, `jax.vmap` over envs |
| 병렬 | 2048~8192 envs 동시. 실습당 1시간이면 수천만~수억 스텝 가능 |

**주의**: 세포밥은 동적 생성이므로 링버퍼(고정 크기, 오래된 것부터 덮어쓰기)로 관리.
