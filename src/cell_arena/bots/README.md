# 봇

학생 에이전트와 **같은 Agent API** 로 작성된 상대. 환경 자체(`cell_arena.core`/`cell_arena.engine`)는 봇을 모르고, 봇도
자기 관측(자기 상태와 시야 안 객체)만 본다. `cell_arena` 패키지 안에 내장돼 있어 설정 파일·판 구성에서는 **파일 이름**으로
부른다 (`bronze` → `cell_arena/bots/bronze.py`, pip 설치 여부와 무관하게 항상 같이 딸려온다).

| 이름 | 그리디로 지내는 시간 | 모드 전환 | 표시 색 |
|---|---|---|---|
| `bronze` | 0% (항상 랜덤워크) | 없음 | (205, 127, 50) |
| `silver` | 20% | 그리디 평균 40스텝 ↔ 랜덤워크 평균 160스텝 | (200, 212, 230) |
| `gold` | 75% | 그리디 평균 150스텝 ↔ 랜덤워크 평균 50스텝 | (240, 190, 0) |
| `diamond` | 100% (항상 그리디) | 없음 | (110, 230, 255) |

공통 메커니즘은 `tiered.py` 의 `TieredBot`. 매 스텝 ε-greedy 로 섞으면 행동이 떨리므로, **모드 자체가 2상태 마르코프
연쇄로 가끔 바뀐다** (한 주기 평균 `mode_cycle=200` 스텝, 그리디 비율 `greedy_frac`).

- 랜덤워크 모드 (`random_walk.py`): 평균 20스텝마다 8방향 중 하나로 방향 전환, 돌진 없음
- 그리디 모드 (`greedy.py`): 위협 도주 > 블랙홀 회피(크기 500 초과) > 먹이 세포 추격(가까우면 돌진) > 화이트홀·밥 > 배회

학습 env 에서는 env 수만큼의 배치로 매 스텝 `act` 가 호출되므로, 새 봇도 배열 연산으로 짜야 학습이 느려지지 않는다.
